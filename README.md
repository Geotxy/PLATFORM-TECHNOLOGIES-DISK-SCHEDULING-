# PLATFORM-TECHNOLOGIES-DISK-SCHEDULING-
Our platform is designed to demonstrate and simulate different disk scheduling algorithms using Python. It allows users to understand how operating systems manage disk requests, determine the order in which requests are processed, and evaluate the performance of different scheduling techniques.
*System Execution
1. Open the Project – Locate and open the project folder containing the Python source code.
2. Run the Program – Execute the main Python file using an IDE such as Visual Studio Code, PyCharm, or through the terminal.
3. Access the Platform – Once executed, the platform will display its main interface or menu.
4. Select an Algorithm – Choose the disk scheduling algorithm you want to simulate (FCFS, SSTF, or SCAN).
5. Enter the Required Inputs – Provide the initial disk head position, disk request queue, and other necessary parameters.
6. Execute the Simulation – Run the selected algorithm to generate the results.

* Input Requirements
The platform requires specific information from the user to perform the disk scheduling simulation.
- The user must input the following below are then Input, Description, and Example in order.
Initial Head Position - Starting Position of Disk Head - 53
Disk Request Queue - List of cylinder positions that need to be accessed - 98, 183, 37, 122, 14, 124, 65, 67
Disk Size - total number of cylinders - 200
Initial Direction - Direction in which the disk head initially moves - Right
* Output Interpretation
The platform generates the following results after execution:
* Head Movement Sequence – Displays the order in which the disk head processes requests.
* Total Head Movement – Shows the total distance traveled by the disk head, measured in cylinders.
* Performance Comparison – Compares the total head movement of FCFS, SSTF, and SCAN to identify which algorithm travels the shortest distance.
* Expected Results
Users should be able to:
1. Execute the three disk scheduling algorithms.
2. View their respective head movement sequences.
3. Calculate and compare total head movements.
4. Identify the most efficient algorithm based on the given requests.
* Conclusion
The platform provides an interactive way to understand disk scheduling algorithms through Python simulations. It helps users visualize disk head movements, analyze results, and compare the performance of FCFS, SSTF, and SCAN.
